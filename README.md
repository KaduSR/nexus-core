# Nexus Core ⚙️

> Core engine para automacao de infraestrutura de provedores de internet (ISP).

## Sobre

Engine central para automatizar processos operacionais de provedores de internet. 
Gerencia monitoramento, conciliacao financeira, integracao com sistemas terceiros 
(IXC, Sicoob) e orquestracao de servicos.

## Stack

TypeScript • Node.js • PostgreSQL • Docker

## Componentes
- Monitoramento de servicos ISP
- Automacao de conciliacao financeira
- Integracao com IXC Soft e Sicoob
- API REST documentada
- Dashboard operacional
